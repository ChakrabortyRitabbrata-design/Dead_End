# Asset inventory

* New world terrain, trees, ruins, gates and atlas: original Java/AWT drawing code
  in `src/main/WorldRenderer.java`, created for this project. No external pack.
* Level 1 cottage, farmstead and garden compositions: original transparent,
  cached pixel artwork drawn by `src/main/LocationArt.java`; no external assets.
* Existing player, undead, dragon and object images under `res`: inherited project
  assets. Original authors/licences are not documented in this repository; this
  change does not assert redistribution permission.
* Existing `res/tile` images, including uncommitted extractions: preserved, not
  used as the new world's environmental artwork. Their provenance is unverified.
* User's screenshots: composition references only; not copied into game assets.
